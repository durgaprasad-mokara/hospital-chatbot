🏥 Hospital Chatbot

A simple, fullscreen web interface for a hospital chatbot integrated with Chatling AI.

🔗 Live Demo: https://gydocare.netlify.app/

📌 Overview

This project provides a clean and minimal chatbot interface designed for hospital-related interactions. It runs entirely in the browser and uses Chatling AI for real-time conversations.

The chatbot is embedded using a simple HTML setup, making it lightweight, fast, and easy to deploy without any backend.

🚀 Features
Fullscreen chatbot interface
No backend required
Easy integration with Chatling AI
Fast and lightweight
Works on desktop and mobile
Ready for deployment
🛠️ Tech Stack
HTML
CSS
JavaScript
Chatling AI

▶️ Usage
Download or clone the repository
Open the index.html file in any modern web browser
The chatbot will launch in fullscreen mode

No installation or server setup is required.
